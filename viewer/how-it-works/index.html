How it works · Qwen3.5-4B

Turn one neuron, and the fridge becomes a mouse.

A language model's MLP layers are full of single units that, pushed hard enough, drag every answer toward one topic, style or persona. This is how that works, using real runs on Qwen3.5-4B.

1

The residual stream is a shared notepad

Each token is a list of 2,560 numbers, the residual stream. It flows through 32 layers. No layer replaces it: each one reads it, computes something, and adds its result back. Whatever ends up in the stream at the top decides the next word.

Fig. 1Every layer reads the stream and adds to it at a ⊕. Layer 5, in red, holds the neuron used in the examples below.

2

A native neuron is one slot in the MLP

Inside every layer, the MLP blows the 2,560 numbers up to 9,216, applies a nonlinearity, and squeezes them back down with a matrix called down_proj. Each of those 9,216 middle values is a neuron: 32 × 9,216 = 294,912 in the model. "Native" means it's a unit the model already has, not a direction we invented.

Fig. 2One of the 9,216 middle values, circled, is neuron n. Whatever it does reaches the stream only through its column of down_proj.

activation
How strongly the neuron fires on this token. Usually near zero.
W_down[:, n]
Its fixed write direction: what it adds to the stream when it fires.
so
Neuron n always contributes activation × W_down[:, n].
3

Steering is nudging one activation, at every token

Hook the input to down_proj and add a constant a to neuron n, on every token of the prompt and the reply. The stream now carries an extra a × W_down[:, n], which every later layer reads. The recipe sizes a so the dose means the same thing at any layer:

Why divideDividing by ‖W_down[:, n]‖ turns activation units into a push whose length is dose × the stream's typical size, so dose −1 shoves the stream by its whole typical length. The median is the atlas's fixed value for each layer, so atlas and Neuronary doses reproduce. Token 0 is left out of the median because its norm is an outlier.

a = dose × median ‖resid‖ leaving layer L (tokens 1:)‖W_down[:, n]‖

What it does

Same prompt, same greedy decoding, one neuron changed.

A switch, not a dialHalf strength only rewords the fridge answer; −1 swaps the whole topic. Across five prompts at −0.5, only the story picks up a mouse. The opposite sign is not "anti-mouse": at +1 the fridge question turns into a list about serving drinks at a party.

5

Finding more: scan a whole layer

Put a different neuron in each row of a batch, generate a short reply to two unrelated prompts, and look for neurons that pull both replies onto the same unexpected topic. One layer is 9,216 runs: about 48 minutes on a MacBook, or about 3 minutes on 8 rented GPUs for about $0.40.

BreakageAt dose −1, 359 of the 9,216 layer-5 neurons (about 4%) and 105 of the layer-12 neurons (about 1%) just break the reply.
